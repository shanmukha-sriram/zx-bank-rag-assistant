# Dataset Documentation

## Overview
The ZX Bank AI Knowledge Assistant is built on the ZX Bank Markdown corpus (from the RAG-Multi-Corpus dataset) — internal knowledge documents covering ZX Bank's banking products and policies (loans, accounts, fees, terms), one document per `.md` file.

## Format
- File type: Markdown (`.md`)
- Location: `data/raw/zx_bank/`
- Structure: heading hierarchy (`#`, `##`, `###`) separates sections such as Eligibility, Documents Required, Interest Rate, Repayment.

## Document Categories
- **Loans:** House Loan, Personal Loan
- **Accounts:** Savings Account, Fixed Deposit
- **Cards:** Credit Cards
- **Policies:** Fee Schedule & General Terms

## Data Quality Notes
- Files are plain Markdown with no consistent front-matter — metadata (category, product name) is inferred from filename and heading structure rather than explicit tags.
- Heading depth and structure vary slightly between documents (see `docs/chunking.md` for how this is handled).

## Limitations
- The corpus is static and manually maintained — no automated sync from a live content system.
- Coverage is limited to what's included in the `RAG-Multi-Corpus` ZX Bank subset; questions outside this corpus are expected to trigger abstention (see `docs/evaluation.md`).
